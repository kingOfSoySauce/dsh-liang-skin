# 滑动变祖 0.1.11

修复皮肤背景与宿主布局的兼容性，恢复外观入口和推理等级绑定操作。

- 保留宿主根容器的固定定位、标题栏高度和弹窗层级，背景使用独立层级；保留已有 Windows 框架透明与 macOS 侧栏修复。
- 外观入口按原生主题按钮结构识别，移除固定类名哈希依赖；点击浅色、深色或跟随系统可切回原生。
- 推理等级绑定改用 DSH 原生 Switch，删除自绘样式和附加说明；标题文字不可点击。
- 背景遮罩统一绘制一次；人像逐张加载与解码，失败图片最多额外重试三次，保持上一张可用人像；停用时清理请求与定时器。

验证：19 个单元测试、11 个浏览器兼容场景、实际客户端构建与 24 张 WebP 的运行时回归通过，构建产物与安装包逐项一致。Grok Build `grok-4.7` / `xhigh`（当前 CLI 最高等级）只读 review 未发现有效问题。本地 Web 已检查原生开关的显示和点击行为，macOS Desktop 已由用户试用。

Windows Desktop 尚无本地实机验证。请报告者升级后完全退出并重开，检查人物显示、档位变化、绑定开关和权限弹窗；相关 Issue/PR 保持开放，待反馈后收尾。跨刷新外观记忆 #9 留待后续，本版未修改皮肤市场。

## 更新

官方 Desktop：在插件管理器或皮肤市场更新 npm 包 `@leon___/dsh-client-liang-intensity-skin` 至 `0.1.11`，完全退出并重新打开 Desktop。

Web：

```sh
dsh plugin --profile web add '@leon___/dsh-client-liang-intensity-skin@0.1.11'
```

安装后完全停止并重新启动 DSH Web。Web profile 与官方 Desktop 的安装状态彼此独立。
