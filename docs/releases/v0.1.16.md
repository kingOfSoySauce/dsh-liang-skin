# 0.1.16 — Desktop 0.2.1-rc.5 / 0.2.2-rc.1 兼容修复

发布日期：2026-11-12

## 修复

- **#23 第三方插件整页透明**：透明背景不再由所有宿主页面共享；非会话整页面板补可读页面底色，菜单/选择器补齐 `--dsw-menu-surface-fill` 等 token，composer 上沿恢复皮肤色渐隐。
- **#24 深色档对比度**：
  - 宿主 `body[data-ds-dark-theme]` 与 `html { color-scheme }` 跟随皮肤档位（启用时镜像、关闭/卸载还原，不写入用户主题偏好），修复 deliverable 文件卡片白底浅字与漏网组件的主题错配；
  - 徽标改为按 `svg > g[clip-path*="badge"]` 结构定位，rect 与字形分别染色，深色档保留金底；
  - composer 规则不再只写到 stage 0–3，补齐深色档。
- **#26 宿主深色 + 皮肤浅色**：浅色档补 `--dsw-alias-bg-module-platform` 等模块表面 token，设置页下拉/选项块不再出现宿主深色 `#353638` 黑块。
- **#25 面板可读性**：默认保留半透明质感；设置 → 滑动变祖 → 外观新增「不透明面板」开关，打开后输入框、气泡、菜单、卡片和侧栏变为完全不透明。
- 菜单、模块平台、文档预览等表面改为映射到皮肤自己的半透明层，不再直接使用宿主浅色/深色字面值。

## 兼容性

- Web：DSH `0.1.7-rc.2` 实测（Chromium 自动化 + 人工截图检查）。
- 官方 Desktop：按 `0.2.2-rc.1` 源码核对选择器与 token；仍需 Windows/macOS 实机复测后确认（报告 #23/#24/#26 的复测会在这里跟进）。
- 现有自动化：91 个单元测试、runtime 用例、14 个浏览器兼容场景通过。

## 已知取舍

- 默认 `layer1/2/3 = 0.58/0.6/0.7`、侧栏 `0.66` 保持不变；报告人认为叠字影响阅读时使用「不透明面板」开关，而不是改变默认外观。
- 旧宿主上出现 `cannot get property "remote.session" without inject` 的非阻断控制台错误（0.1.7-rc.2 的 model directory 调用），不影响皮肤显示；后续随 Desktop 实机验证一并确认。
