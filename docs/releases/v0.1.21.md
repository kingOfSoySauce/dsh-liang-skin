# 0.1.21 — 智能体团队滑块节点

发布日期：2026-11-13

## 新增

- 滑块终点新增“最大思考档位 + 智能体团队”节点（显示为 `梁祖 · Max 智能体团队`）：滑到尽头会保存最大思考档位，并为当前会话开启智能体团队协作；从终点滑到下面任何档位会自动关闭团队，模型选择面板里的团队开关与滑块双向同步。
- 设置 → 滑动变祖 → 滑块新增「滑块绑定智能体团队」开关，描述「滑块兼容智能体团队」；默认开启，关闭后滑块完全恢复原行为。
- 仅在客户端真正提供 Agent Teams Remote 与 `agentTeam` 投影（DSH `0.2.2-rc.2` 起的稳定团队实现）时出现该节点；不支持的客户端保持原滑块。

## 修复

- 深色档「深度求索中，用时 …」恢复金色：适配 DSH 0.2.2 起使用的 `--dsw-alias-label-deep-diving` / `--dsw-alias-label-deep-diving-shimmer` token，保留旧宿主规则，浅色档保持原生。
- web profile 移除 rc.2 已不存在的 `@deepseek-ai/dsh-experimental-agent-team-profile` bundle 依赖，改用内置稳定团队。

## 兼容性

- Desktop `0.2.2-rc.2` 实机安装。
- Web `0.2.2-rc.2` 启动验证；`0.2.2-rc.1` 及更早版本按能力检测隐藏团队节点。
- 93 个单元测试、14 个浏览器兼容场景、runtime 用例（含团队开关开/关/失败路径）通过。
